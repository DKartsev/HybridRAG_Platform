# Hybrid RAG Platform

Проект содержит ноутбук с гибридным RAG-пайплайном (retrieval + шаблоны + генерация), интерфейсом Gradio и инструментами для автотестирования.

## Содержимое
- `HybridRAG_Platform.ipynb` — основной ноутбук с кодом пайплайна, UI, тестами и метриками.

## Быстрый запуск в Colab
1. Откройте Colab и загрузите `HybridRAG_Platform.ipynb`или перейдите в [ноутбук](https://colab.research.google.com/drive/153nr1p01MGkXBvg7XxT2HL7FzulHGwXB?usp=sharing)
2. Выполните ячейки сверху вниз.
3. Задайте необходимые ключи/конфигурацию в соответствующих ячейках (если используются внешние сервисы).
4. Запустите Gradio-интерфейс и откройте ссылку в браузере.

## Локальный запуск
1. Установите зависимости, указанные в ноутбуке.
2. Запустите все ячейки сверху вниз.
3. Откройте Gradio-интерфейс.

## Тестирование
Автотесты запускаются из вкладки/ячейки тестирования в ноутбуке. Результаты сохраняются в JSON.

## Примечания
- Ноутбук рассчитан на запуск в Colab и в локальном окружении.
- Для корректной работы RAG используйте актуальные данные и настройки retrieval.
